# ☕ Cup'O'Chino — Animated Coffee Brand Website

A modern, responsive, single-page coffee brand website built for Cup'O'Chino. The website combines an elegant coffee-inspired visual design with smooth scroll animations, interactive sections and a responsive mobile experience.

The project is built using HTML5, CSS3, Vanilla JavaScript and GSAP 3 without any frontend framework or build system.

---

## ✨ Features

* 🎨 Modern coffee-inspired UI
* 📱 Fully responsive design
* ⚡ Smooth GSAP animations
* 🖱️ Scroll-based interactive animations
* ☕ Interactive coffee journey section
* 📋 Interactive coffee menu cards
* 🧭 Smooth navigation and scrolling
* 🍔 Responsive mobile navigation menu
* 📍 Location section with Google Maps
* 💬 Customer testimonials section
* 📱 Mobile-specific animation fallback
* 🎯 Semantic HTML structure
* 🌐 Google Fonts integration
* 🚀 No build tools or installation required

## 🚀 Getting Started

This is a static website, so no Node.js or package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/cupochino-website.git
```

### 2. Navigate to the project

```bash
cd cupochino-website
```

### 3. Open the website

You can simply open:

```text
index.html
```

in your browser.

### Recommended: Run with a local server

If you are using VS Code, you can use the **Live Server** extension.

Or run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 🎬 Animations

The project uses **GSAP 3** for its animation system.

Some of the main animations include:

* Hero text reveal
* Navigation scroll effects
* Smooth anchor scrolling
* Coffee bean animations
* Coffee roasting animation
* Grinding animation
* Tamping animation
* Espresso extraction animation
* Scroll-triggered section transitions
* Mobile fade-in animations

GSAP libraries are loaded through CDN, so no local installation is required.

## 📝 Customization

Most of the website content can be customized directly from `index.html`.

### Brand Name

Update the logo and brand text in the navigation and footer.

### Hero Section

Search for:

```html
hero-title
```

to change the main heading and tagline.

### Menu

Search for:

```html
menu-card
```

to update coffee names, descriptions, flavour notes, and intensity levels.

### Contact Information

Update the contact information, opening hours, delivery details, and phone/email information in the contact section.

### Location

Update the Google Maps iframe URL and address information in the location section.

### Social Media

Update the Instagram, Facebook, and X/Twitter links in the footer.

### Testimonials

Search for:

```html
testimonial
```

to change customer reviews and names.
